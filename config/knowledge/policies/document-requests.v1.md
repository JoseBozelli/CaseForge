## Requesting documents
Request each required document with its exact document type and a clear deadline.

## Missing documents
If a requested document has not arrived, send the requester a reminder before taking other action. Repeated silence after two reminders is a reason to escalate.

## Wrong document received
When the uploaded document type does not match the requested type, do not accept it and do not close the case. Request the correct document again and state the expected type.
